# NexTerm

NexTerm 是一个基于 **Tauri 2.0** 构建的、功能完整的早期生产候选（pre-1.0）跨平台**终端与远程管理应用**，目标定位为现代开源版的 MobaXterm。它将本地 PTY 终端、SSH 远程连接与文件管理（SFTP）能力整合进一个可自由拖拽、分屏、多标签的工作台中。

> 核心链路（本地 PTY、SSH/SFTP、Telnet、串口、端口转发、凭据保险库、主题系统、设置面板）已经可用，并带有自动重连、断点续传、ZMODEM 接收与远程文件本地编辑等进阶能力；1.0 前的主要缺口是核心模块拆分、端到端集成测试与发布签名/公证。

## 功能特性

- **本地终端**：基于 `portable-pty` + xterm.js，支持多标签、分屏与隐藏标签保活。
- **SSH**：密码 / 私钥 / 证书 / SSH Agent 认证、主机密钥 TOFU 校验、ProxyJump 跳板机、交互式终端、保活与断线自动重连。
- **Telnet 与串口**：Telnet（ECHO / SGA / NAWS / TTYPE 协商）与串口会话（端口探测、波特率预设）。
- **端口转发**：本地（`-L`）、远程（`-R`）与动态 SOCKS5（`-D`）转发，独立管理面板。
- **SFTP**：目录浏览、文件/文件夹上传下载、递归传输、断点续传、暂停/取消/重试、冲突策略、传输队列。
- **工作区**：Dockview 多面板、可持久化布局、自定义标签页与右键菜单、重启后恢复标签与滚动缓冲。
- **效率**：会话管理器、树形分组、SSH config / MobaXterm / PuTTY / NexTerm JSON 导入导出、快速连接、`Ctrl+K` 命令面板、可配置快捷键。
- **终端**：WebLinks 可点击链接、Unicode11、选中即复制、中英文核心界面。
- **凭据**：可选加密保险库，使用主密码 + Argon2id + AES-256-GCM 保存 SSH 密码与私钥口令。
- **外观**：Web 2.0 经典后台风格，支持明亮 / 暗黑 / 跟随系统；终端字体、字号、光标、回滚、行高可调。

## 安全说明

- **主机密钥校验**：首次连接需确认 SHA256 指纹，后续自动比对；不匹配会中止连接。
- **凭据保险库**：启用「记住凭据」后，密码与私钥口令使用 Argon2id 派生密钥、AES-256-GCM 加密后写入应用配置目录；应用重启后保险库默认锁定，需要主密码解锁。未启用时凭据仅保存在内存中。
- **known_hosts**：保存在应用配置目录的 `known_hosts.json`，支持导入/导出 OpenSSH `known_hosts` 格式（导出可选哈希主机名）。
- **终端快照**：滚动缓冲快照以明文保存在本地 `localStorage`，默认只保存本地会话（远程会话输出可能包含敏感信息，可在设置 > 终端中改为保存所有会话或关闭）；快照数量有上限，设置中可一键清除。
- **SFTP 范围**：支持浏览、上传/下载（含递归）、新建/重命名/删除，暂不支持权限修改。

详细说明见 [`doc/p3-ssh-sftp.md`](doc/p3-ssh-sftp.md)。
