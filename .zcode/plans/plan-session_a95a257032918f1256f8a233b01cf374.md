将参考图（Android 2.x）标签栏配色进一步复刻到 Eclair 主题的标签栏，亮/暗变体统一使用同一套金属样式。改动仅涉及 2 个文件（`src/theme/tokens.css`、`src/index.css`）。

## 1. 新增 2 个标签栏专用渐变 token（tokens.css）

在 `eclair-light` 与 `eclair-dark` 两个块中各新增（两个变体取值完全相同，实现"亮/暗都用这种样式"）：

```css
--gradient-tab-active: linear-gradient(180deg, #f7f7f7 0%, #e0e0e0 45%, #b6b6b6 100%);   /* 选中：亮银金属 */
--gradient-tab-inactive: linear-gradient(180deg, #5a5a5a 0%, #454545 42%, #1a1a1a 100%); /* 未选中：上亮下暗金属块 */
```

用独立 token 而非复用 `--gradient-chrome` / `--gradient-panel-title`，避免影响共享这两个 token 的下拉框、弹出菜单、面板标题等。

## 2. 替换标签栏规则（index.css eclair 区段）

- `.app-tab-strip > button` 与 `.dv-tab.dv-inactive-tab`：背景从"半透明黑罩"改为不透明的 `var(--gradient-tab-inactive)`；文字提亮为 `#efefef`。
- `[data-active='true']` 与 `.dv-active-tab`：从 `var(--gradient-chrome)` 改为 `var(--gradient-tab-active)`；顶部白色高光从 0.35 加强到 0.55、描边加深到 0.14，贴近图中银色标签的金属感；文字 `#1a1a1a`。
- 未选中 hover：改为与 overflow 按钮相同的图层写法（白色 0.12 叠加在 `--gradient-tab-inactive` 之上），并给 dockview 的 `.dv-tab.dv-inactive-tab` 补上此前缺失的 hover 反馈，与设置窗口标签条行为一致。
- 分隔线加深：`.dv-tab` 右边框与 `--dv-tab-divider-color` 从 0.45/0.5 → `rgba(0, 0, 0, 0.55)`，未选中标签保留左缘 1px 高光形成立体分隔。
- 其余不动：条底渐变（`--gradient-panel-title`）、溢出按钮/渐隐遮罩、状态灯、图标等。
